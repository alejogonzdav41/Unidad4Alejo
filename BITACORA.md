# Bitácora — Dragones en el cielo

## Proceso

1. Se creó la estructura Vite solicitada, sin modificar los archivos de configuración de Git existentes.
2. Se modelaron ocho agentes con Kuramoto: cada actualización calcula la influencia promedio de fase y el parámetro de orden global `R`.
3. Se definieron cuatro parejas audiovisuales (Brasa, Niebla, Aurora y Éter), cada dragón con color, movimiento, timbre y oscilador propios.
4. Se incorporaron controles de acoplamiento, frecuencia natural, dispersión, caos, armonía y perturbación individual.
5. Se verificó la compilación de producción con `npm run build`.

## Para evidenciar en GitHub

Antes de entregar, ejecuta la experiencia con `npm run dev`, toma una captura en caos y otra en sincronización, y realiza un commit descriptivo desde tu flujo habitual de Git. Esta bitácora documenta el alcance técnico sin alterar la configuración del repositorio.
